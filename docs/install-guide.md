# Voice2Doc インストール手順書

English version: [install-guide.en.md](install-guide.en.md)
対象バージョン: 1.0.0-beta.3
配布物: `Voice2Doc-Setup.exe`（NSISインストーラー、約300MB）

## 1. 動作環境

- OS: Windows 10 / 11（64bit）
- 管理者権限: **不要**（ユーザーレベルインストール、`$LOCALAPPDATA\Voice2Doc` にインストールされる）
- **Vibe**（https://github.com/thewh1teagle/vibe/releases）: **各自でインストールする（同梱していない）**。音声認識に使う `vibe-server.exe` と、動画の音声抽出に使う `ffmpeg.exe` は Vibe に含まれている。アプリは `%LOCALAPPDATA%\vibe\`・`%LOCALAPPDATA%\Programs\vibe\`・`Program Files\vibe`・Vibe のアンインストール情報（HKCU/HKLM）・スタートメニューのショートカットから自動検出する（別の場所は設定で指定できる）
- インターネット接続:
  - インストール時: Visual C++ Runtime / WebView2 Runtime が未導入の場合、自動ダウンロードするため必要
  - 初回起動時: 音声認識モデル（約1.6GB。Vibe がダウンロード）とローカル LLM（約2.6GB。アプリがダウンロード）の取得に必要（下記「4. 初回起動時の注意」参照）
- ディスク空き容量: インストール本体で約0.9GB + 初回起動時の音声認識モデルで約1.6GB + ローカル LLM で約2.6GB、合計 **約7GB以上**推奨（Vibe 本体の容量は別）

## 2. インストール手順

1. まだであれば Vibe（https://github.com/thewh1teagle/vibe/releases）をインストールする。
2. `Voice2Doc-Setup.exe` を配布先PCの任意の場所（デスクトップ等）にコピーする。
3. `Voice2Doc-Setup.exe` をダブルクリックして実行する（管理者権限は不要、そのまま実行できる）。インストーラーの表示言語は Windows の表示言語で決まる（日本語の Windows なら日本語、それ以外は英語）。
4. ウィザードの案内に従って進める。
   1. ようこそ画面 → 「次へ」
   2. 使用許諾契約（MITライセンス）→ 内容確認後「同意する」
   3. インストール先フォルダの選択（既定: `%LOCALAPPDATA%\Voice2Doc`。特別な理由がなければ既定のままでよい）
   4. インストール実行
      - Visual C++ Redistributable、WebView2 Runtime が未導入の場合、Microsoft公式サイトから自動ダウンロード（SHA256ハッシュ検証あり）→サイレントインストールが行われる。導入済みの場合はスキップされる。
      - アプリ本体（`Voice2Doc.exe` と関連ファイル一式）がインストール先にコピーされる。
      - デスクトップおよびスタートメニューにショートカットが作成される。
   5. 完了画面が表示される。
      - 音声認識に Vibe を利用していること、Vibe が未導入なら初回起動時に導入することが表示される。「**Voice2Doc を起動する**」にチェックが入っており、そのまま「完了」を押すとアプリが起動する。初回起動時の案内に従い、Vibe の配布ページの **Assets** から Windows 用インストーラー（例: `vibe_3.3.2_x64-setup.exe`。2026年11月13日時点の、Intel・AMD の CPU の Windows 用の名前です。数字の部分は新しい版で変わります）を入れること、その後 Vibe がモデルをダウンロードし、終わったら Vibe の画面は × で閉じてよいことが表示される。
      - 「起動前に再起動が必要な場合があります」と表示されることがある。VC++/WebView2を新規インストールした場合は、案内に従って一度PCを再起動してから起動することを推奨する。
      - 一部コンポーネントのインストールに失敗した旨のメッセージが出た場合は、本書「5. トラブルシューティング」を参照。
5. デスクトップまたはスタートメニューの「Voice2Doc」アイコンから起動する。初回起動ウィザードの前提条件チェックで Vibe（vibe-server.exe）が見つからない場合は、Vibe の案内とダウンロードページへのリンクが表示される。Vibe をインストールしてから「再確認」を押す（アプリの再起動は不要）。別の場所に入れた場合は「vibe-server.exe の場所を指定する」から指定できる。前提条件の4項目（VC++・WebView2・FFmpeg・vibe-server）がすべて「準備完了」になるまで「次へ」は押せない（上級者向けに「確認せずに進む」もある）。

## 3. アンインストール手順

1. スタートメニューの「Voice2Doc」→「Uninstall」、または「設定」→「アプリ」→「Voice2Doc」から「アンインストール」を選択する。
2. 確認画面で「アンインストール」を実行する。

**⚠️ 重要な注意（既知の制限）**: アンインストールを実行すると、インストール先フォルダ（`%LOCALAPPDATA%\Voice2Doc`）が丸ごと削除される。このフォルダにはアプリ本体だけでなく、**設定ファイル（config.json）・処理履歴・キャッシュも同じ場所に保存されている**ため、アンインストールと同時にこれらのユーザーデータもすべて失われる。設定や処理履歴を残したい場合は、アンインストール前に `%LOCALAPPDATA%\Voice2Doc` フォルダを手動でバックアップしておくこと。Vibe は別のアプリなので、話書きのアンインストールでは削除されない。

## 3.5 ショートカットのアイコンについて

インストーラーは `Voice2Doc.ico` をインストール先に配置し、デスクトップとスタートメニューのショートカットをそのアイコンに向けて作り直します。
古いアイコンが表示される場合は、Windows のアイコンキャッシュが残っています。エクスプローラーを再起動するか、
`ie4uinit.exe -show` を実行するか、サインアウト/再起動してください。

## 4. 初回起動時の注意

- 既定の音声認識モデル（`ggml-large-v3-turbo.bin`、約1.6GB）は、Vibe をインストールしたときに Vibe が `%LOCALAPPDATA%\github.com.thewh1teagle.vibe\` へダウンロードする。アプリは、音声認識のたびに自動でモデルをダウンロードしない。
- 設定の「文字起こしモデル」で別のモデルを選んで「保存」したとき、そのモデルがこの PC に無ければ「音声認識モデルをダウンロードします。ダウンロードに時間が必要です。」というダイアログが出る。「ダウンロード」を押すとアプリが取得し（完了するまでは取得済みのモデルで動作）、「キャンセル」を押すと保存しない。
- インストーラー自体にはこのモデルファイルは同梱されていない。
- ダウンロードには回線状況により数分程度かかる場合がある。インターネット接続が必須。
- ダウンロード中もアプリの他の操作は可能だが、音声認識（文字起こし）はダウンロード完了まで実行できない。
- ローカル LLM（Gemma 4 E2B、約2.6GB）は、GPU（AMD・Intel・NVIDIA。Vulkan 対応）があれば自動で GPU で動かし、無い・合わない場合は CPU で動く。GPU のドライバーは最新にしておくこと。設定の「モデル」タブの「LLM の実行装置」で、自動 / GPU / CPU を選べる（実際に使っている装置も表示される）。GPU で動かしてアプリが強制終了した場合は、次回から自動で CPU になり、案内が一度だけ表示される。

## 5. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Windows によって PC が保護されました」と表示される（SmartScreen） | インストーラーはコード署名されていないため表示される。このリポジトリの Releases から入手したものなら「詳細情報」→「実行」で進める |
| 「スマート アプリ コントロールがブロックしました」と表示され、管理者として実行しても起動しない | Windows 11 のスマート アプリ コントロールが、署名のないアプリを止めている（許可する方法は無い）。導入するには「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」→「アプリとブラウザーの制御」→「スマート アプリ コントロールの設定」で**オフ**にしてから、もう一度インストーラーを実行する。**注意: 多くの Windows のバージョンでは、一度オフにすると Windows のリセット（再インストール）をしない限りオンに戻せない。** |
| インストール完了画面で「一部のコンポーネントでエラーが発生しました」と表示される | Visual C++ RedistributableまたはWebView2 Runtimeの自動インストールに失敗している。以下から手動インストールする。<br>・VC++ Redistributable: https://aka.ms/vs/17/release/vc_redist.x64.exe <br>・WebView2 Runtime: https://developer.microsoft.com/en-us/microsoft-edge/webview2/ |
| アプリ起動後、画面が真っ白/表示されない | 約10秒で白い画面を検知し、自動で再読み込み→GPUを使わない描画（安全モード）での再起動を試す（直ったときは設定の「環境設定」に解除ボタンが出る）。それでも駄目なら案内が出る。WebView2 Runtimeが正しく導入されていない可能性もあるので、上記WebView2を手動インストール後、PCを再起動して再度起動する。報告時は `logs` フォルダのログを添える |
| 起動直後に「起動に失敗しました」エラーダイアログが出る | ダイアログのエラー内容を確認する。VC++ Runtime未導入が原因のことが多い |
| 音声認識が「モデルダウンロード中」から進まない | インターネット接続を確認する。回線速度によっては数分〜10分程度かかることがある |
| 「vibe-server.exeが見つかりません」・Python 版の音声認識で動いている旨のバナーが出る | Vibe をインストールする（https://github.com/thewh1teagle/vibe/releases の **Assets** にある `vibe_3.3.2_x64-setup.exe`）。入れたあとは警告の「再確認」を押せば再起動なしで使える。既定以外の場所に入れた場合は、設定の「モデル設定」で `vibe-server.exe` のパスを指定する |
| 動画ファイルで「FFmpegが見つかりません」と表示される | Vibe のフォルダ（`vibe-server.exe` と同じ場所）に `ffmpeg.exe` があるか確認する。無ければ Vibe を入れ直すか、`ffmpeg` を `PATH` に通す |
