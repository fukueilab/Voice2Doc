### 1.2 LLM libraries (inside `llama_cpp/lib`)

The DLLs of the Vulkan build of llama-cpp-python (`llama.dll`, `ggml*.dll`, `ggml-vulkan.dll`, `mtmd.dll`) are compiled from llama.cpp /
ggml (MIT). A CPU build of the same libraries is bundled as a fallback (`llama_cpp/lib_cpu`). The Vulkan loader library (Vulkan runtime)
and GPU drivers are **not** included; they come with the user's GPU driver. The import libraries (`*.lib`) of the wheel are not bundled.

### 1.3 Application icon

The Voice2Doc application icon (`assets/icon.ico`, generated by `scripts/make_icon.py`) is original artwork drawn by the
project from simple shapes and is covered by the [MIT License](LICENSE). No third-party icon assets are used.
