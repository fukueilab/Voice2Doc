    ⚙️ 設定

    アプリケーションの設定を変更できます

    チェックすると、処理メニューに表示しません
    メイン画面のプロンプト選択カードに表示される説明文です
    LLMに依頼するプロンプトを編集できます
    マークダウンファイルの保存先を指定できます。空の場合はデフォルトのoutputフォルダに保存されます
    マークダウンファイルに音声認識の生テキストを含めます

    音声認識はvibeのvibe-server.exeを利用しています

    選んだモデルがこの PC に無い場合は、保存するときにダウンロードするかどうかを確認します
    任意のモデルの指定が可能です
    自動: GPU（AMD・Intel・NVIDIA。Vulkan 対応）が使えれば GPU、使えなければ CPU で動かします。GPU: GPU を優先します（使えないときは CPU）。CPU: 常に CPU で動かします。GPU でうまく動かないときは CPU を選んでください。保存すると、再起動なしで反映されます。
    表示する言語を切り替えます。編集していない初期プロンプトと音声認識の言語も、選んだ言語に合わせて入れ替わります
    画面が表示されなかったため、GPU を使わない描画に切り替えています。表示が少し重く感じられる場合があります。問題が起きなくなったときは、通常の描画に戻せます。
    アプリの表示モードを切り替えます
    処理履歴の詳細画面でダウンロードするときの初期の形式です（画面上で都度変更もできます）
